# Taste

## Communication style
- Communicates in Spanish using informal voseo ("podemos", "querés", "implements"). Confidence: 0.95
- Prefers being offered concrete options (A/B/C) with pros/cons before any implementation. Confidence: 0.9
- Accepts well-justified recommendations confidently when reasoning is clear ("Me gusta la opcion a"). Confidence: 0.85
- Values honest pushback and honest technical verdicts over agreeable answers — willing to hear "don't do this". Confidence: 0.9
- Asks strategic/advisory questions before tactical ones — wants framework/tooling decisions explored before code is written. Confidence: 0.9

## Workflow preferences
- Wants to research/verify the right tool or framework before committing to a migration or new dependency. Confidence: 0.85
- Prefers evaluating tradeoffs (cost vs benefit) explicitly before adopting a technology, not just adopting for novelty. Confidence: 0.85
- Appreciates decision matrices / comparison tables that map "if your situation is X → do Y, if Z → do W". Confidence: 0.8
